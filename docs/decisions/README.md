# Active decision records

There are no active decision records. Current behavior is specified by
[`../design.md`](../design.md) and [`../specs/`](../specs/).

Create a decision record only when its rationale remains materially useful for
an active migration, live tradeoff, or easy-to-regress architectural boundary.
It explains a choice and links the specification that incorporates it; it never
overrides current design or specification. Archive it after that rationale no
longer needs active implementation attention.
