# Graph audit

Use this instruction set when the human asks for a careful review of the current research graph.

Read the graph and its rendered research view from the pointers in the RCP task contract. Look for
claims that have no supporting evidence, edges that do not explain a relationship, duplicate nodes,
and summaries that overstate what the graph's standing supports. Report observations separately from
recommended human actions. Do not edit canonical `.research` files.
