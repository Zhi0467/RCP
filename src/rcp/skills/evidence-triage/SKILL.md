# Evidence triage

When reviewing material, preserve the distinction between primary artifacts, exact source records,
human decisions, and assistant summaries. State what each item supports, what it does not support,
and what remains uncertain. Prefer a small number of traceable observations over a broad unsupported
summary. Never turn a suggestion into an accepted project fact.
